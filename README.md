## 📌 Visão Geral
Sistema desenvolvido em PHP (Vanilla MVC) voltado para coordenadores e secretarias escolares. Ele permite que pais agendem visitas à escola de maneira automatizada, enviando notificações via e-mail (PHPMailer / SMTP).

## 🚀 Recursos
- 📅 **Calendário Dinâmico:** Visualização de horários disponíveis.
- ✉️ **Notificações Automáticas:** Disparo de emails para visitantes e coordenadores.
- 🔐 **Painel Admin Seguro:** Gestão de segmentos, horários de funcionamento, e administradores.
- 🤖 **Integração Básica com IA:** Estrutura preparada para automações com Gemini/Ollama no back-office.
- 🎨 **Responsivo:** UI moderna adaptada para mobile e desktop.
