# Guia de Contribuicao

Obrigado por se interessar pelo agenda-escolar-php, sistema de agendamento academico e gestao de visitas para escolas.

## Como contribuir

1. Faca um fork do repositorio.
2. Crie uma branch descritiva para sua alteracao.
3. Envie um Pull Request explicando o que foi mudado e por que.

## Sugestoes de contribuicao

- Melhorias no fluxo de agendamento.
- Novos templates de notificacao por email.
- Correcao de bugs no painel administrativo.

Toda contribuicao construtiva e bem-vinda!
